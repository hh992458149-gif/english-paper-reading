# 离线 HTML 与 Word 对照稿

## 先整理一份配对内容

保留原 PDF 和读者最新手改稿。按论文实际结构盘点题名、作者、DOI、版本、章节、段落、公式、图表、参考文献与声明。给段落和图表分配稳定标识，并记录原 PDF 页序。双栏、跨页和合并单元格要对照可见页面复核。

先做一份逐段配对的英文和中文，再生成两种阅读稿。图注与正文分开，保留原图的比例、图例、标尺和面板号。宽表可按记录重新排版，每行仍要能找回材料、配方、条件、指标、单位、引文及合并表头的含义。参考文献保留英文著录并附中文题名。缺失值、原稿疑点和识别不清处在相应位置注明。

## HTML 阅读页

可从[便携试读页](../assets/reader.html)复制布局、语言切换、字号和书签功能。试读页只含同一长句的两处节选。为新论文替换题名、来源、段落、锚点、书签键和示例续读位置，再按新原件补齐图、表及正文。读者已有认可的版式时优先沿用。

- 桌面让英文和中文左右对应，窄屏让每段英文与它的翻译相邻排列。把样式、脚本和展示所需图片放进 HTML，关闭网络也能读。原 PDF 和 Word 若与网页一起交付，使用相对文件链接。
- 提供原文、译文和对照视图，字号调整，打印，以及可跳转的章节和图表目录。原图支持放大查看，保留完整双语图注。
- 从已确认的阅读记录生成精读断点。手动书签单独记录到当前浏览器，按论文及版本区分。浏览器无法保存时给出可见提示。

## 可批注的 Word

让正文保持可选择、可编辑。标出原 PDF 的位置，Word 页码独立编排。对照表使用自动行高及重复表头，检查分页后的图文归属。按实际需要给宽表安排横向分节，检查页脚和页码的接续。使用读者现有的模板时保留其批注和已确认的改动。

## 交付前核对

- 从两稿按稳定标识回查同一段、同一数值和同一表行，核对单位、正负号、计算基准、图号、来源页和引文。
- 离线试用语言切换、字号、目录、图像放大、精读断点、书签重载、打印和附带文件链接。分别看宽屏与窄屏。
- 打开或渲染最终 Word，检查图表、公式、截字、分页和空白页。若缺少渲染工具，交付时具体说明已核到哪一步。生成阅读稿后沿用读者实际停下的位置。
