# 阅读记录与交接

先找读者指定项目中的文献索引、最新交接或单篇笔记，检查题名、版本和下一句原文。文件名中的日期可能早于记录内的更新日期。沿用已有笔记、词汇表和方法库的工作版；首次保存且没有既有结构时，一篇论文一份 Markdown 即可。

## 一份可接着读的笔记

```markdown
# 论文题名

- 来源与版本：DOI 或来源链接，原 PDF 相对位置，版本日期
- 实际精读到：原 PDF 第几页，章节、第几段，最后讲过哪一句
- 下次从这里开始：原 PDF 第几页，章节、第几段，下一句英文原文
- 阅读材料：HTML、Word 各自的完成情况与相对路径
- 待核问题：例如某个条件只见于补充材料
- 篇末三问、词汇、方法入库和归档：分别记实际完成情况
```

读取同名论文的另一版时，先对齐章节和原句，再更新页码。区分读者实际逐句读过、整段翻译过、仅展示过和明确跳过的内容。只有书签、输出稿或自动预读时，保留原精读记录；缺少确切位置时，让读者提供最近一句或一处标注。保存后同步项目已有的索引和交接。

## 词汇与方法

读者要求整理词汇时，按词形与语境去重，保留英文、句中中文义、原句、来源页和复习栏。区分读者实际提问的词和建议补充词。同一术语在不同论文里有实质不同的含义时分别记录。

方法记录注明目的、原理、样品、对照、仪器、步骤、参数、重复、计算口径，以及这项测量能支持的判断。保留原 PDF 页码或补充材料出处；综述归纳与原始实验条件分别标出。追加到已有工作表时，沿用原编号、公式、来源链接和列结构。

## 结束一篇

按读者指示记录“精读完成”或“转作参考”，保留最后位置与待核项。需要归档时保存原 PDF、双语稿、三问与单篇记录，有阶段快照则记录版本或校验值。切换新篇后，仍可按原记录查回上一份资料。
